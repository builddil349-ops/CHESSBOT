# CHESSBOT

Локальный шахматный помощник для Windows: читает доску и список ходов с экрана Google Chrome, восстанавливает позицию и показывает подсказку Stockfish. Интерфейс на русском языке. Текущая версия — **1.1**.

## Возможности

- Захват доски и таблицы ходов из окна Chrome без чтения файлов браузера.
- Игра за белых и чёрных; цвет игрока и поворот доски настраиваются отдельно.
- Стрелка и подпись хода в окне помощника, которое остаётся поверх остальных окон.
- Распознавание списка ходов, рокировки, взятия на проходе и превращения пешки.
- Локальная история партии, кнопки «История», «Новая партия» и «Сброс ходов».
- Встроенные шаблоны обычных и рисованных фигур; автоматическое запоминание оформления по началу партии.
- Проверка позиции перед подсказкой и отбрасывание устаревших результатов распознавания.

Это обработка изображения: анимации, перекрытая доска, неправильные границы захвата и незнакомые фигуры могут мешать распознаванию. Все существующие темы не включены в программу. Если позиция не подтверждена, подсказка скрывается.

## Запуск готового приложения

1. Запусти `CHESSBOT.exe` в папке проекта. Сборка не требует установленного Python.
2. Выбери официальный Windows EXE движка [Stockfish](https://stockfishchess.org/download/). Движок запускается отдельным процессом локально.
3. Открой партию в Google Chrome. Укажи свой цвет и при необходимости поворот доски.
4. Нажми «Выбрать доску и ходы» и последовательно выдели доску целиком (ровно 8 × 8 клеток) и таблицу ходов. Координаты должны охватывать таблицу от номера хода до правого столбца.
5. Оставляй выбранные области видимыми. При перемещении или масштабировании страницы выдели их заново. Окно CHESSBOT держи сбоку от доски.

Для нового оформления начинай захват на стартовой позиции либо после первых одного–двух ходов: помощник сохранит профиль фигур и фона. Кнопка «Темы» показывает состояние профилей. «Новая партия» запускает настройку новой партии, а «Сброс ходов» очищает сохранённую историю.

## Запуск из исходников

Проверено на **Windows x64, Python 3.12** с Tkinter. Для других версий Python совместимость двоичных зависимостей не проверялась. В официальном установщике Python должен быть включён компонент Tcl/Tk.

Открой PowerShell в папке проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe trainer.py
```

Английская OCR-модель включена в `eng.traineddata`. Если файл отсутствует или повреждён, его можно восстановить из официального репозитория с проверкой SHA-256:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\download-model.ps1
```

## Сборка EXE

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Python .\.venv\Scripts\python.exe
```

Результат — `CHESSBOT.exe` и его копия в `dist/`. В EXE включаются OCR-модель, библиотеки распознавания и лицензии зависимостей. Stockfish выбирается отдельно и не встраивается в сборку. Бинарные сборки, внешний движок, резервные копии и локальные данные исключены из Git.

## Локальные данные

История: `%LOCALAPPDATA%\ChessBotTrainer\moves.txt`. Профили оформления: `%LOCALAPPDATA%\ChessBotTrainer\themes`. Путь сохранён для совместимости с предыдущими версиями. В исходный репозиторий эти данные не включаются. Приложение не отправляет захваченные изображения на сервер; скрипт восстановления модели обращается к официальному репозиторию Tesseract.

## Файлы проекта

| Файл | Назначение |
| --- | --- |
| `trainer.py` | Интерфейс, захват Chrome, синхронизация позиции, история, Stockfish |
| `screen_ocr.py` | Чтение таблицы ходов через Tesseract |
| `move_list.py` | Разбор обозначений и восстановление допустимой позиции |
| `standard_board.py` | Распознавание фигур по изображению доски |
| `standard_templates.py`, `illustrated_templates.py` | Шаблоны фигур |
| `adaptive_themes.py` | Обучение и хранение профилей оформления |
| `build.ps1`, `hook-tesserocr.py` | Сборка приложения в Windows EXE |
